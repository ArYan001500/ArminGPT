# ArminGPT

یک اپلیکیشن چت فارسی خانوادگی برای اندروید، ساخته‌شده با Expo و یک backend امن برای Groq.

## قابلیت‌ها

- صفحه شروع اختصاصی با نام شرکت مهندسین فرزانگان آرمین پژوه
- رابط فارسی راست‌به‌چپ و پاسخ‌های سریع آفلاین
- اتصال امن به Groq از طریق backend
- کلید Groq فقط روی backend نگهداری می‌شود
- family access key، محدودیت تعداد درخواست و محدودیت اندازه پیام

## اجرای محلی

1. فایل `.env.example` را با نام `.env.local` ایجاد و مقادیر آن را تنظیم کنید. کلید Groq باید جدید و خصوصی باشد.
2. backend را اجرا کنید:

```powershell
npm.cmd run server
```

3. اپ را در ترمینال دیگری اجرا کنید:

```powershell
npm.cmd start
```

پس از بازشدن اپ، آدرس backend و `FAMILY_ACCESS_KEY` را در صفحه تنظیم اتصال وارد کنید. این اطلاعات
در حافظه امن گوشی ذخیره می‌شوند و داخل APK قرار نمی‌گیرند.

برای تست روی شبکه خانه، آدرس backend شبیه `http://192.168.1.20:8787` است. برای استفاده دائمی،
backend باید روی یک سرویس دارای HTTPS منتشر شود.

## انتشار backend روی Render

1. پروژه را در یک مخزن خصوصی GitHub قرار دهید و آن را به Render متصل کنید.
2. در Render گزینه Blueprint را انتخاب و فایل `render.yaml` همین پروژه را معرفی کنید.
3. در Environment، دو مقدار زیر را وارد کنید:
   - `GROQ_API_KEY`: کلید جدید Groq
   - `FAMILY_ACCESS_KEY`: یک رمز طولانی و تصادفی مخصوص خانواده
4. بعد از Deploy، آدرس HTTPS سرویس مثل `https://armingpt-backend.onrender.com` را بردارید.
5. در صفحه تنظیم اتصال ArminGPT، همان آدرس و همان `FAMILY_ACCESS_KEY` را وارد کنید.

کلید Groq فقط روی Render می‌ماند. اپ تنها رمز محدود خانواده را نگهداری می‌کند.

## ساخت APK خانوادگی

بعد از ورود به حساب Expo:

```powershell
npx.cmd eas-cli@latest login
npx.cmd eas-cli build --platform android --profile preview
```

پروفایل `preview` یک فایل APK قابل نصب مستقیم تولید می‌کند.
آدرس backend و رمز خانواده بعد از نصب داخل خود اپ وارد می‌شوند، بنابراین APK به یک سرور خاص قفل نیست.

## نکات امنیتی

- `GROQ_API_KEY` را هرگز داخل متغیرهای `EXPO_PUBLIC_*` قرار ندهید.
- `GROQ_API_KEY` را در چت، APK یا مخزن Git ذخیره نکنید.
- یک `FAMILY_ACCESS_KEY` طولانی و اختصاصی انتخاب کنید.
- برای استفاده بیرون از شبکه محلی، backend را فقط پشت HTTPS منتشر کنید.
- family access key مانع استفاده اتفاقی می‌شود، اما جای حساب کاربری کامل را نمی‌گیرد.
